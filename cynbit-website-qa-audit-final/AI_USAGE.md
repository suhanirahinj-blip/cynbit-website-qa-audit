# AI Usage Disclosure

AI assistance was used to help organize the manual QA observations into structured test cases, bug reports, an audit summary, and improvement recommendations.

The website interactions and issue observations in this report were supplied by the tester from their manual review. AI assistance was used for wording, formatting, classification suggestions, and documentation structure.

AI assistance did not independently execute browser tests, inspect Cynbit's source code, access backend logs, validate server-side behaviour, or perform security testing. Severity and priority labels are provisional suggestions and should be reviewed by the development team.

All final findings should be checked against the actual website and supported with genuine screenshots or recordings before submission.
